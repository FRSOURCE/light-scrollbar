attach - arguments ​

Possible arguments that can be used in attach method.

bar ​

General settings for scrollbar "bar" thickness and offset.

Default value

ts
bar: {
  y: {
    width: 6,
    offset: [0, 0],
  },
  x: {
    height: 6,
    offset: [0, 0],
  },
},

Type

ts
bar?: BarConfig;
ts
export type BarConfig = {
  y?: {
    width?: number;
    offset?: [number, number];
  };
  x?: {
    height?: number;
    offset?: [number, number];
  };
};

enableRail ​

Shows a rail - the background track under the scrollbar thumb. The rail is an optional plugin, so it has to be passed in plugins as well; without it enableRail only logs a warning. See the Rail example.

ts
import { rail } from "@frsource/light-scrollbar/rail";
import "@frsource/light-scrollbar/dist/rail.css";

attach(el, { enableRail: true, plugins: [rail] });

Default value

ts
enableRail: false,

Type

ts
enableRail?: boolean;

rail ​

Rail thickness and offset, same shape as bar. Every value that is not set is taken from bar, so with enableRail alone the rail has exactly the size and position of the scrollbar. Used only when enableRail is on.

MOUSE AREA

With the rail on, the whole rail reacts to the mouse like the scrollbar does: hovering, pressing and dragging work anywhere on the rail, also when it is thicker than the scrollbar or placed with a different offset. When both rails are visible, the corner where they cross is sized by the thicker of the rail and the scrollbar, and the scrollbar stops where the rail ends.

Default value

values of bar

Type

ts
// every value that is not set is taken from `bar`
rail?: BarConfig;
ts
export type BarConfig = {
  y?: {
    width?: number;
    offset?: [number, number];
  };
  x?: {
    height?: number;
    offset?: [number, number];
  };
};

plugins ​

Optional features that live in separate entries, so they are added to your bundle only when you import them. Currently available: rail from @frsource/light-scrollbar/rail.

Default value

ts
plugins: [],

Type

ts
plugins?: LightScrollbarPlugin[];
ts
export type PluginContext = {
  config: InternalConfig;
  innerElement: HTMLElement;
  outerElement: HTMLElement;
};

export type PluginAxisUpdate = {
  // whether the scrollbar of this axis is shown (content overflows the container)
  visible: boolean;
  // length of the track the thumb moves along - the container edge without the corner,
  // when both scrollbars are visible
  length: number;
};

export type PluginUpdate = {
  x: PluginAxisUpdate;
  y: PluginAxisUpdate;
};

// a strip along the container edge, like `bar`: `size` - thickness, `offset` - distance from the edge
export type PluginHitArea = {
  size: number;
  offset: number;
};

export type PluginInstance = {
  // additional strips that react to the mouse like the scrollbar does (hover, press, drag);
  // the corner where both scrollbars cross is sized by the thickest strip of the other axis
  hitArea?: Partial<Record<Axis, PluginHitArea>>;
  // called whenever the scrollbars are recalculated (resize, content change)
  update?: (state: PluginUpdate) => void;
  // called on `detach()`, before the original DOM structure is restored
  detach?: () => void;
};

export type LightScrollbarPlugin = {
  name: string;
  // called once by `attach()`; return nothing to stay inactive for this instance
  setup: (context: PluginContext) => PluginInstance | void;
};

className ​

ClassName used to target HTMLElement that has overflow: auto on it, meaning is scrollable container.

Default value

ts
className: "light-scrollbar",

Type

ts
className?: string;

disableFocusPrevent ​

By default emitting focus event is disabled, means when scroll is initialized from this container no focus event will be emitted.

Default value

ts
disableFocusPrevent: true,

Type

ts
disableFocusPrevent?: boolean;

wrapperPlacement ​

In order to create custom scrollbar, at this moment only possible solution is to wrap scrollable container with wrapper. This plugin can create wrapper inside your container and switch node and its all classes/attrs/listeners from original container to inner child, or create outside wrapper.

Default value

ts
wrapperPlacement: WrapperPlacement.inside,

Type

ts
wrapperPlacement?: WrapperPlacement;
ts
export enum WrapperPlacement {
  "inside" = "inside",
  "outside" = "outside",
}

wrapperElement ​

There is possibility to create wrapper element from given HTMLElement passed via this parameter.

Default value

null

Type

ts
wrapperElement?: HTMLElement;

showOnHover ​

Scrollbars can be visible only when hover on container.

Default value

ts
showOnHover: false,

Type

ts
showOnHover?: number | false
